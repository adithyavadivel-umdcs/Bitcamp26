# 20-Hour Build Order

## Hour 1-2
- create Android project
- set up Firebase
- set up Maps SDK
- set up anonymous auth
- verify map renders on device

## Hour 3-4
- create lobby flow
- join by invite code
- basic player list in lobby
- host configures map center and radius manually

## Hour 5-6
- location permission flow
- live location updates
- write player positions to database
- subscribe to lobby state

## Hour 7-8
- ready check
- validate all players near start point
- start match transition
- role assignment
- generate hider codes

## Hour 9-10
- head start state
- seeker freeze enforcement
- match screen
- hiders see seeker
- seeker sees only self by default

## Hour 11-12
- shrinking circle UI
- shrink timer
- out-of-bounds elimination
- endgame if all hiders eliminated or seeker DQ

## Hour 13-14
- multiple hotspots
- tap-to-claim
- grant one of two powerups
- powerup activation flow

## Hour 15-16
- code entry UI for seeker
- catch eligibility checks
- correct code eliminates eligible hider
- incorrect code fails cleanly

## Hour 17-18
- local step tracking
- level display in lobby/loading
- rally point open in Google Maps

## Hour 19
- outdoor test
- fix biggest bugs only

## Hour 20
- rehearse demo
- cut anything unstable
