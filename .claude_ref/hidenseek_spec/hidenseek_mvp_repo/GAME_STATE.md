# Canonical Game States

WAITING
- lobby exists
- players may join
- host configures match

READY_CHECK
- players confirm readiness
- server validates players are near start point

HEAD_START
- match has begun
- seeker frozen
- hiders may move

RUNNING
- active match
- shrink logic active
- hotspots active
- code catch eligibility active
- powerups active

ENDED
- game over
- winners decided
- stats shown
