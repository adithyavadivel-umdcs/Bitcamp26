# Demo Script

1. Host opens app and creates private lobby
2. Two or three players join by invite code
3. Show lobby player levels and total steps
4. Show all players gathered at start point
5. Host starts game
6. Explain seeker head start freeze
7. Show hiders moving away while seeker stays frozen
8. Show live seeker marker visible to hiders
9. Show circle shrink warning and shrink
10. Show player claim hotspot and gain powerup
11. Show seeker get within catch range of a hider
12. Show seeker enter the correct 6-digit code
13. Eliminate the hider
14. Show eliminated hider open rally point in Google Maps
15. Finish game and show winner + steps gained
