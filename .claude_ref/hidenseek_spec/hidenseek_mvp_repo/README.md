# Hide and Seek Hackathon MVP

Android-first live-location hide-and-seek game.

## Core pitch
Private invite-code outdoor hide-and-seek game.
One seeker, multiple hiders.
Live map.
Shrinking play area.
Multiple hotspots grant powerups.
Seeker can eliminate a hider only by entering that hider's unique 6-digit code while inside catch radius of that hider.
Steps tracked locally to show player level.

## What this package is
This repo package is a copy-pasteable MVP plan plus starter code stubs.
It is not a complete runnable app.

## MVP goals
- get people moving outside
- create a social outdoor experience
- prove the core game loop in 20 hours
- keep critical game rules server-authoritative
- aggressively cut risky systems

## Non-goals
- no public lobbies
- no friend-of-friend codes
- no image capture
- no voting
- no computer vision
- no background gameplay
- no Google Fit
- no Health Connect
- no in-app routing
- no cosmetics backend
- no dwell-based hotspot capture
