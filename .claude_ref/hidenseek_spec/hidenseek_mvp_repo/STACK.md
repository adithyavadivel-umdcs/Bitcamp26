# Tech Stack by Necessity

## 5 - absolutely required
- Android Studio
- Kotlin
- Jetpack Compose
- Google Maps SDK for Android
- Maps Compose
- FusedLocationProviderClient
- Android runtime permissions for precise location
- Firebase Authentication with anonymous auth
- Firebase Realtime Database
- Firebase Security Rules
- Firebase Cloud Functions
- SensorManager step counter

## 4 - strongly recommended
- Navigation Compose
- ViewModel
- Repository pattern
- one shared GameBalance.kt
- one shared game state machine
- Google Maps intent for rally point
- Firebase Emulator Suite for local testing

## 3 - useful if time allows
- Firebase Crashlytics
- cleanup functions for expired lobbies
- basic server-side attempt throttling for code spam

## 2 - optional polish
- Hilt
- analytics
- small admin cleanup dashboard

## 1 - explicitly cut
- Firebase Cloud Storage
- CameraX
- image voting
- public lobby discovery
- full social graph
- background location gameplay
- Health Connect
- Google Fit
- in-app routing
- cosmetics backend
